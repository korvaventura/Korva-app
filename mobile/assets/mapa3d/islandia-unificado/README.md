# Islandia unificada

Fuente aportada: `Meshy_AI_Iceland_3D_Topographi_1006175550_image-to-3d-texture.glb` (73.443.148 bytes, 1.435.706 triángulos).
Versión móvil: 220.000 triángulos, 135.897 vértices, textura JPEG 2048². Reducción offline con meshoptimizer; el teléfono no ejecuta simplificación.
Empaquetar con `mobile/scripts/empacarModeloUnificado.mjs`, pasando GLB, JPEG, carpeta de salida, carpeta temporal de diagnóstico y `mobile/scripts/islandia.calibracion.json`.
Modelo artístico; ruta y alturas calibradas a su superficie, no datos GPS de navegación.
